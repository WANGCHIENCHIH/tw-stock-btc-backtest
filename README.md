# 台股與 BTC/TWD 日線回測

這個 Python 命令列工具從證交所或幣託取得最近 120 根日線，用 10,000 元台幣模擬均線（MA）或漲跌幅（ROC）策略。程式先用前一日收盤價判斷是否持有，再用下一日開盤價模擬成交，最後列出每筆交易與扣費後報酬率。

## 快速開始

準備 Python 3 和網路連線，程式只使用標準函式庫。下載並解壓縮專案，或執行以下指令：

```sh
git clone https://github.com/WANGCHIENCHIH/tw-stock-btc-backtest.git
cd tw-stock-btc-backtest
python beginner.py
```

預設跑台積電的 20 日均線。已下載專案的 Windows 使用者也可以雙擊 `start-local.cmd`。要換標的或指標，在專案資料夾執行：

```sh
python beginner.py --stock 2317
python beginner.py --btc --indicator roc --period 10
```

**如何讀結果**　每筆交易會列出日期、買賣方向、開盤成交價與前一日指標。最後兩行彙總成交次數、期末淨值與扣費報酬。例如期末淨值為 9,800 元，代表起始本金 10,000 元在這段期間虧損 200 元，扣費報酬率為 −2%。

## 指令參數

| 參數 | 可用值 | 省略時 | 用途 |
| --- | --- | --- | --- |
| `--stock` | `2330` 台積電、`2317` 鴻海 | 未選 BTC 時用 `2330` | 讀取指定股票的台幣報價 |
| `--btc` | 開關，後面不用填值 | 關閉 | 選 BTC/TWD。與 `--stock` 只能擇一 |
| `--indicator` | `ma`、`roc` | `ma` | 選均線或漲跌幅 |
| `--period` | 整數 2～60，含兩端 | 20 | 指標往回看的長度。台股按交易日，BTC 按 UTC 日線，含週末 |
| `-h` 或 `--help` | 開關 | 關閉 | 列出指令格式後結束 |

## 指標與回測規則

| 你想觀察什麼 | 指令 | 數值的意思 |
| --- | --- | --- |
| 價格是否站上近期平均 | `python beginner.py --indicator ma --period 5` | MA5 是最近五個收盤價的平均。前一交易日收盤高於均線就持有，低於或等於就空手。 |
| 一段時間內價格上漲多少 | `python beginner.py --indicator roc --period 10` | ROC10 比較前一交易日與再往前十個交易日的收盤價。從 100 漲到 105 就是 +5%，大於 0 就持有，否則空手。 |

把第一條指令的 5 改成 20，再比較第一筆買入日期、成交次數與扣費報酬。均線天數越小，單日價格的影響越大；天數越大，線通常越平滑、反應越慢。ROC 天數變大，是改用更早的價格當起點，百分比可能變大也可能變小。一次只改一項，並核對兩次輸出的起訖日期相同。

### 訊號在哪一天變成交易

假設週三到週五收盤依序為 98、100、102 元。週五收盤後，MA3 是 100 元，102 高於均線，產生持有訊號。若當時空手，下個交易日開盤 105 元，程式就用 105 元模擬買入。若已經持有，當天不會再買。這裡可以看出三個不同的數字：指標是 100、判斷用的收盤是 102、成交用的價格是 105。

MA 和 ROC 描述已發生的行情。回測要問的是「過去照這條規則做，扣費後剩多少？」程式沒有輸出明天的預測價或上漲機率。在同一段歷史挑出表現最好的週期，容易把偶然的波動當成規律；要檢查預測能力，可先固定週期，再拿另一段較晚的資料驗證。
打開 [beginner.py](beginner.py)，先看所選市場的資料函式，再看回測函式。

1. `fetch_days(stock)` 對證交所的 `STOCK_DAY` 發送 HTTP GET。`stockNo` 是股票代號，`date` 指定查詢月份。從 JSON 的 `fields` 找出日期、開盤與收盤欄位，再從 `data` 逐列讀取，把民國年加 1911、移除價格的千分位逗號。逐月往前收集台北今天以前最近 120 筆日線，按日期排列，休市日不補價。可在[證交所個股日成交資訊](https://www.twse.com.tw/zh/trading/historical/stock-day.html)核對。
2. `fetch_btc_days()` 從幣託讀取最近 120 根完整 UTC 日線，包括週末。API 的查詢範圍使用秒，回傳時間戳是毫秒。BTC 可買入小數數量，每次買賣假設手續費 0.1%，賣出稅設為零。
3. `backtest()` 用前 61 筆準備指標，在後 59 個交易日模擬。前一交易日收盤後產生訊號，下一筆日線開盤時模擬成交。台股買入可負擔的整數股，剩餘現金保留。賣出訊號出現時全數賣出。台股每次買賣假設手續費 0.1425%，賣出另計 0.3% 稅。期末仍持股時，用最後收盤價扣估計賣出費稅計算淨值。
4. 台股用普通交易開盤價近似零股成交價，使用原始股價，忽略股息、拆併股、最低手續費與滑價。回測結果只代表這組假設下的價格表現。

## 開發與測試

目前程式和測試都在專案根目錄。打開 [beginner.py](beginner.py)，搜尋下列函式名稱即可找到位置。修改後，在同一資料夾執行 `python -m unittest -v`。[現有測試](test_beginner.py)

### 加一個指標，例如 EMA（指數移動平均線）

1. 在 `main()` 找到 `--indicator` 的 `choices`，加入 `"ema"`。這一步讓命令列認得這個名稱。
2. 在 `backtest()` 找到 `if indicator == "ma"`。現有的 `else` 一律算 ROC，先把它改成明確的 `elif indicator == "roc"`，再加 EMA 分支。每個分支都要給兩個結果：`value` 是印出來的指標值，`hold` 是這一天想持有還是空手。後面的買賣與扣費可以沿用。
3. EMA 讓近期價格有較大權重。一個容易手算的版本是用最初 N 筆收盤的平均作起點，此後每筆都算「舊 EMA ＋ 2/(N+1) ×（新收盤 − 舊 EMA）」。成交當天只能使用前一日為止的 EMA。可在 `test_beginner.py` 加一例：N=3，前三筆收盤 98、100、102，起點為 100；第四筆收盤 104，EMA 應為 102，第五筆開盤才可依此成交。

### 改手續費或賣出稅

| 想改哪一項 | 在 beginner.py 搜尋 | 現行教學假設 |
| --- | --- | --- |
| 台股買、賣手續費 | 檔案上方的 `FEE` | `0.001425`，每邊 0.1425% |
| 台股賣出稅 | 檔案上方的 `SELL_TAX` | `0.003`，賣出收 0.3% |
| BTC 買、賣手續費 | `backtest()` 的 `fee = 0.001 if crypto else FEE` | 改 `0.001` 這一項；目前每邊 0.1% |
| BTC 賣出稅假設 | 同函式的 `sell_tax = 0 if crypto else SELL_TAX` | BTC 取 0 |

例如要模擬 BTC 每邊 0.2%，填 `0.002`。成交額 10,000 元時，單邊手續費會從 10 元變成 20 元。這些值目前寫在程式裡。改完用一組已知買賣價格重算期末淨值，並同步更新對應測試的預期金額；期末仍持有的部位也會按賣出費稅估值。

### 如果要接美股或期貨

| 擴充方向 | 建議寫在哪裡 | 第一個要驗證的差異 |
| --- | --- | --- |
| 美股現貨 | 在根目錄 `beginner.py` 的 `fetch_days()` 旁新增函式，例如 `fetch_us_days(symbol)`，同樣回傳按日期排序的（日期、開盤、收盤）。在 `main()` 的互斥群組加入選項並接上來源。 | 依美國交易日與時區剔除未收盤日線，確認拆股前後價格口徑。把 `backtest()` 的市場費率、可買股數及 `main()` 的幣別顯示一起調整。若本金以台幣計，先換算美元；若整場用美元，輸入和輸出都要標 USD。 |
| 期貨 | 建議在根目錄新建 `futures.py`，放契約行情和期貨損益計算，從 `beginner.py` 的 `main()` 呼叫。MA、ROC 仍可從收盤序列算出方向。 | 每筆資料要能辨認契約及到期月。一口多單的毛損益是「點數變動 × 每點金額」，空單方向相反。另計每口成本、保證金與每日結算；跨月要指定何時平舊倉、開新倉。先測一口上漲 2 點、假設每點 50 元，毛利應為 100 元。 |
